Set up LaTeX render

3. Set up passthrough

The Hugo renderer escapes characters like backslash ‘\’, which causes trouble when writing LaTeX expressions.

Enabling and configuring the Goldmark passthrough extension would solve the issue. The extension preserves raw Markdown within delimited snippets of text, including the delimiters themselves.

markup:
  goldmark:
    extensions:
      passthrough:
        delimiters:
          block:
          - - \[
            - \]
          - - $$
            - $$
          inline:
          - - \(
            - \)
        enable: true

Use Code block

To create code block, simply use markdown syntax

Code block with backticks and language specified

```<language>

your demonstration code here

```

Code block with line number

Code blocks also support line numbers

```<language> {linenos=true}

your demonstration code here

```

Limit code block size

Sometimes the code you are demonstrating is too long and it feels redundant to show the entire code. This can be resolved by limiting the vertical size of the block. Add the following code to the /themes/PaperMod/assets/css/extended/blank.css you modified before:

.post-content pre, code{
    max-height: 45em;
    overflow-y: auto;
}

A scroll bar in y axis will appear for oversized code block. However if line number is also shown, an issue appears that the line numbers and code will use different scroll bars.

Round corner for code block

Add/modify the following code in /themes/css/common/post-single.css

.post-content .highlight pre {
    background-color: var(--theme) !important;
    margin: 0;
}
