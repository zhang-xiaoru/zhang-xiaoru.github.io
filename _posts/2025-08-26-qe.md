## DFT Calculations using Quantum Espresso

### Set up QE-emacs-modes

[QE-emacs-modes](https://www.google.com/url?sa=i&url=https%3A%2F%2Fwww.quantum-espresso.org%2Fwp-content%2Fuploads%2F2022%2F03%2Femacs_user_guide.pdf&psig=AOvVaw0mUHaYtuOGspq6R_A09X5p&ust=1756332145160000&source=images&cd=vfe&opi=89978449&ved=0CAYQrpoMahcKEwj4l6eevamPAxUAAAAAHQAAAAAQBA) is a great open-source Emacs major modes which helps editing the input files of Quantum Espresso. The pacakge provide features like highlighting, basic auto-indentation and usful command like create template input file for various programs. 

#### Install

First download the packages and unzip the downloaded file.

```bash
wget http://pwtk.ijs.si/download/QE-modes-7.4.tar.gz

tar -zxvf QE-modes-7.4.tar.gz
```

Next, run the `install.sh` file under the unziped directory. The default install directory is `$HOME/.emacs.d/`. The installing directory can be changed by specifying  `prefix=<your_prefered_location> install.sh`. 

#### Specify QE-modes in Emacs

To enable QE-modes in Emacs, we need to specify that in the `user-init-file` of Emacs, which usually lies at `$HOME/.emacs`. You can simply create one under the same location if you don't have that file. 

Next, you need to copy the content in `qe-modes.emacs` under the unziped directory into the `.emacs` file. If your installation location is default, you are done. Otherwise, you need to specify the installation location at

```
(add-to-list 'load-path (expand-file-name "/your_path/qe-modes/"))
```

#### Useful functionality

**File name patter**

QE-modes automatically recoganize any file that end with `.in`. It can also be more specific to different function included in Quantum Espresso like ph.x, pw.x. Simply name your input files in the format as `pw.*.in`. 

**Insert temeplate input file**

You can insert a template input file for various QE functions like pw, ph, dynmat. Simply enter `M-x prog-insert-template` in Emacs. 

`M-x` measn press metadata key and 'x' at same time. On Mac, metadata key is "ESC". `prog` stands for the input files for various programs liks pw, ph, etc.
